# El-Biyahe! stock images

Free-licensed stock photography for the [El-Biyahe!](https://github.com/vinsu-hub) Los Banos tourism app.

All images are from Wikimedia Commons under CC BY, CC BY-SA, CC0, or Public Domain.
Per-image attribution is in [`destination-photo-manifest.json`](./destination-photo-manifest.json)
and mirrored in the app repo at `scripts/destination-photo-manifest.json`.

Web-sized bundles are published as GitHub Releases (see the Releases tab).
The app fetches them via `pnpm assets:download`.
